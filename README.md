# BirdMaster

A bird watching companion app for iOS that helps users identify, log, and learn about bird species.

## Features
- Bird species handbook with descriptions
- Sighting logging with location and photos
- Photography tips for bird photography
- SwiftData persistence
- Pre-seeded species database

## Architecture
- MVVM pattern with SwiftData
- Swift Package Manager project
- iOS 17+ with SwiftUI

## Requirements
- iOS 17.0+
- Swift 5.9+

## Building
```bash
swift build
```
